# 宣传素材

本轮公开素材是巨无霸手绘版，目标是让麦门爱好者看懂项目创意、比赛身份和 GitHub 入口。用户明确要求加巨无霸与薯条，并授权交主开发放进 GitHub 吸引用户。图片为原创手绘宣传插画，不是软件界面或私人足迹。

## 本地工作材料

未采用草稿仅保留本地、不作为本轮公开素材。原始手绘稿、旧排版草稿、地图截取、QR 草稿、渲染脚本和接受检查脚本／报告都是本机工作材料，不要求随本轮宣传图提交；公开文案不链接这些本地文件。

2026-10-10 已核对公开 v0.4.0 ZIP 哈希，并以独立浏览器走通记录、照片、备份、分享卡和合成响应下的想去清单；与真实外部体验者反馈分开。默认固定端口在本机被已有服务占用，界面接受检查用隔离端口，不据此声称本机正常默认启动或真实手机／微信发送通过。
