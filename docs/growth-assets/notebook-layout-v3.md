## 一页内的关系

以 1080 × 1440 为基准，整体为一张暖白纸，不套另一层卡片。标题、照片、旁注、店名与理由相互呼应，不用完整宽度分隔线把每一块切开。留白用来组织内容，不保留旧卡理由下面的大空洞。

| 部位 | 位置与关系 | 实现约束 |
| --- | --- | --- |
| 品牌／状态 | 页首约 5% 处，左侧小品牌文字，右侧一处细红笔椭圆圈住状态 | 保留“尚未打卡”，不重复计划章；不能增加实际到访暗示 |
| 标题 | 左侧两行松弛圆笔字，约占页高 15%；上行墨黑，下行红笔，短下划线跟随文字 | 自定义标题按真实字宽换行，不固定改写用户标题；长标题最多两行后逐级减字号，不挤掉照片和资料 |
| 照片＋旁注 | 中段约 42% 高，白色相纸边，无硬黑框，无胶带；倾斜约 1°，留边缘小批注与曲线箭头 | 原照片保持比例，全图／裁切沿用原开关；照片略斜，来源文字仍水平。批注基于真实公开标签，不能所有店都写“圆圆的这家” |
| 城市／店名 | 紧接照片，同一左侧红笔位置符号；城市短下划线，完整名称在下一行 | 名称长时自然换行，不能截掉关键店名；城市隐藏时不画虚构城市标签 |
| 理由＋插画 | 下段理由在左，汉堡薯条在右，细蓝笔线从理由收笔处延伸；插画约占页宽 25% | 两者是一组，不能插画独自钉在页角。长理由占满宽度时插画下移或缩减，不覆盖文字；无理由时仍有稳定留白，不填虚构故事 |
| 来源／署名 | 页底小字，与主体保持呼吸空间 | 至少 22px；公开例明确“计划示例”，本人照片则使用真实来源语义，不冒充官方照片 |

笔触统一：细圆笔墨线、短红色铅笔圈／下划线、少量黄笔重点、蓝色注记线。不是字体倾斜、每块贴纸或每栏画边框。纸纹要浅，装饰位置确定，正文保持可读且不旋转。

## 动态文字与真实信息

动态标题和短笔记可采用 [LXGW WenKai 官方字体](https://github.com/lxgw/LxgwWenKai) Regular 配合构图，避免假粗体与 Ma Shan Zheng 毛笔字。该字体基于 Klee One，官方 [OFL 1.1 许可](https://raw.githubusercontent.com/lxgw/LxgwWenKai/main/OFL.txt)已核对；本地随包分发时保留许可，等待字体就绪再导出。地址、操作、来源用已有清晰正文字体。字体是同一纸页的组成部分，不能当成这轮唯一改动。

样稿中“圆圆的这家”只用于该公开千岛湖照片的构图示例。通用卡片旁注使用门店已有公开特色标签／用户输入；没有可靠内容则只画短指示线，不自动编造体验。巨无霸涂鸦是主题装饰，不表示用户实际吃过；探店餐品区仍以用户记录为准。

三类卡共用纸色／笔触／字体／注记关系：下一站是照片＋想去理由；探店是照片＋真实日期、餐品与随记；足迹以准确地图为中心，真实计数像页边批注，禁止虚构路线或统计。界面地图标签、目录和详情沿用同语言，但装饰量明显低于导出卡，保留正常按钮／焦点／滚动。
