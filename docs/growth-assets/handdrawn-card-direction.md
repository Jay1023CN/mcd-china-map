# 麦麦手绘手账｜统一卡片方向

2026-10-10 作者直接反馈“卡片ai味道什么的太重了 没有特色 风格化”，并明确范围：门店地图标签、列表／详情，以及探店、足迹、下一站分享卡全部统一。以下是实施参考，尚不是已上线功能或实际导出结果。

实施进度：基础纸页／墨线／胶带照片／城市章已进入实际页面和三类 Canvas 产物，本对话已目视审阅七张截图／导出图。标题字体和两主题差异继续补充，v0.10 暂未发布。下面两张生成图仍是参考，不与上述实际产物混称。

## 共用设计语言

| 元素 | 统一规则 |
| --- | --- |
| 纸页 | 奶油色 `#fff8e7`，浅纸纹，不做脏旧边沿；左侧少量活页孔可选，资料主体有留白。 |
| 墨线 | `#29251e`，带轻微手绘起伏的单线／短笔划；避免为每一块叠圆角、细边框、阴影。 |
| 红／黄／蓝 | 红 `#d44632` 用地名印章和行动；黄 `#edc448` 用纸胶带与标题笔划；蓝 `#3983a8` 少量用于理由／随记横线。 |
| 字体 | 大标题有粗笔或手写字形，正文、来源、地址用清楚中文字体。动态文字不能靠整张图片代替；新字体需有可公开分发的来源、许可与本地回退。 |
| 照片 | 使用现有原照片；白边、两小段胶带与轻微错位。可装饰外框，不能重绘门店或把原图加工成虚构场景。 |
| 印章 | 城市标签／内容状态，不写奖项或虚构到访。下一站明确“计划 · 尚未打卡”，不能套“已到访”章。 |
| 涂鸦 | 少量原创钢笔蜡笔巨无霸、薯条、箭头，呼应已采用主海报；不做每张满屏图案。 |

## 各组件如何共用

| 组件 | 构图 | 装饰强度 |
| --- | --- | --- |
| 地图门店标签 | 小照片＋城市与短店名，像夹在地图边的小票签；完整店名在详情。 | 最少：一条墨线或小黄划，不加汉堡、不挤小地图。 |
| 门店列表 | 真实照片贴入纸页，城市印章、店名和两三行介绍顺着页面排；来源／地址正常显示。 | 低：照片上两段胶带，卡片不用大白色圆角容器。 |
| 门店详情 | 沿用现有弹窗／手机底部详情卡，内部是手账页；照片、完整店名、资料横线、收藏／记一餐顺序清楚。 | 中：小城市印章、边角涂鸦；参考图的旁白和大汉堡在手机实现中缩减。 |
| 探店分享卡 | 标题和日期、照片、门店（按选项）、餐品与随记；随记像铅笔写在横线上。 | 中：照片胶带、城市章、一个小餐品涂鸦。 |
| 足迹分享卡 | 真实统计像页边手记，地图保持现有准确轮廓；用墨线和实际数据组成版面。 | 中：取消整齐四个大圆角指标方块，数字直接排在纸上；不要为好看改统计或地图。 |
| 下一站分享卡 | 大标题、计划章、照片、门店和想去理由；没有操作按钮。 | 中高：与分享参考图同方向，计划标识始终可读。 |

手机界面比导出卡更克制：装饰可以轻微倾斜，动态正文和按钮保持水平。分享卡沿用现有 1080 × 1440 尺寸、主题选择与字段开关；两种主题仍属于同一手账风格，不做两套无关设计。

标题字体建议已与主开发对齐为 [Google Fonts Ma Shan Zheng](https://raw.githubusercontent.com/google/fonts/main/ofl/mashanzheng/METADATA.pb)，官方标为中文手写类别，字体文件 `MaShanZheng-Regular.ttf`。[官方 OFL 许可](https://raw.githubusercontent.com/google/fonts/main/ofl/mashanzheng/OFL.txt)已核对，分发时保留版权及许可；字体本地加载、导出等待加载成功，正文仍用现有 Noto。主开发正在验证，不把建议写成已全部生效。

## 实现与验收边界

- 保留现有 HTML／CSS、Canvas 和交互接口，不迁移框架。可用共享 SVG／Canvas 路径表现墨线、纸胶带、章和涂鸦，避免各组件重复发明风格。
- 字体、照片和装饰走已有本地资源策略；等待字体后再导出。手绘噪点固定，刷新或导出不使布局随机变化。
- 手机按钮至少 44px，正文至少保持原可读字号；关闭、返回、焦点、滚动与安全区仍正常。装饰不挡点击或资料，长店名和长随记有真实换行。
- 无照片／不展示城市门店的卡片仍成形；照片全图／裁切、本人照片优先、复制／保存／分享入口均保留。
- 由主开发对改动组件做定向检查：地图选店→详情→收藏／记一餐，三类卡生成，长标题与缺图／字段开关；公开示例截图记录实际实现。设计参考不计为这类检查通过。
- 当前公开网页与现有海报继续使用原入口。新风格只有实际部署与导出结果可核对后，才作为产品更新宣传。
