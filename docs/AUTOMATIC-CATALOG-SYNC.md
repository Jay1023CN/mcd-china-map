# 官方菜单与门店目录自动同步

`.github/workflows/sync-official-catalogs.yml` 每周一北京时间 05:30 运行，也可以在 GitHub Actions 里手动运行。

## 菜单

同步器读取麦当劳中国官网的汉堡和卷、饮品、麦咖啡、小食、甜品、早餐、500 大卡套餐和开心乐园餐分类页。新条目会加入目录并暂时标为“新品”；官网分类不再列出的旧条目会保留，显示“官网分类未列出 · 可补记”。限时条目过期后会离开“新品”筛选，但仍可用于补记历史餐食。

官网新闻中发布、但没有出现在这些菜单分类页里的临时活动组合，不保证自动发现；这类活动需要额外的新闻页解析规则。

## 门店

同步器重新分页读取麦当劳中国大陆官方餐厅披露名单。分页缺失、结果不完整或大陆门店数量异常下降时，任务会失败并停止发布。已有门店坐标只在官方编号、名称和城市都匹配时沿用；新门店没有可靠坐标时继续留空。

港澳台目录仍采用各自已核对的来源快照，本工作流不会刷新它们。披露名单不是实时营业状态，也不代表每家门店当天供应哪些餐品。

有实际目录变化时，工作流才会提交数据、重建页面并触发 Pages、Render 构建和回归检查；只变化检查时间时不会提交或部署。临时采集缓存会在任务结束时清理，不上传页面截图。
