# 麦麦中国地图的入口与更新

日常使用打开固定主站：https://jay1023cn.github.io/mcd-china-map/ 。Windows 下也可以双击 `打开在线地图.cmd`，它只让默认浏览器打开这个地址，不安装 Python、不启动本地服务。

页面、公开门店资料和门店照片在主站统一发布。用户继续使用同一个网址，刷新后取得线上版本。我们维护线上内容，用户不用为了补一张照片或一个地址重新下载本地包。

## 两种入口

| 入口 | 页面与公开资料从哪里来 | 更新方式 |
| --- | --- | --- |
| 主站、`打开在线地图.cmd` | GitHub Pages 上的页面与静态资源 | 更新并部署主站；用户刷新 |
| `启动网页版.cmd`、`启动.cmd` 等本地入口 | 当前解压包中的页面、门店快照、图片和程序 | 当前版本仍需更新本地包 |

在线 CMD 里只保留固定主站地址。页面内容、照片和门店目录没有写进这个 CMD。网页的实际内容由我们部署的主站提供。

现有本地启动脚本则会运行包内 Python 服务，使用包内资料构建页面。它们没有自动下载新版页面或公开门店资料的功能；不能把本地包描述成跟随主站自动更新的启动器。

## 资料如何进入主站

官方公示、门店查询和其他公开资料 → 采集与交叉核对 → 我们的门店目录和图片 → 构建、部署主站 → 浏览器加载。

详情里的官方来源链接让用户查看出处。它们不是页面每次打开时实时查询的接口。只修改来源网址不会自动刷新门店资料，仍需完成采集、核对和发布。

## 个人记录与订单同步

网页版的手动记录、收藏、照片和备份由当前浏览器保存。公开资料在线更新不会把这些个人记录写入门店公共目录。

Token 登录和订单同步需要后端服务。现有本地服务在本机完成这部分工作，`启动网页版.cmd` 使用的网页会话保存在本地 `private/web`，没有接入 GitHub Pages。公开主站目前支持手动记录和收藏；订单同步继续使用本地入口。

在线主站与本地服务目前是两个独立入口。让线上页面直接连接本地同步服务，还需要专门实现连接方式和权限校验，当前尚未实现。

## 已核对的代码

- `启动网页版.cmd`：创建本地运行环境后启动 `scripts/web_api.py`。
- `scripts/web_api.py`：启动时构建本地页面，提供同源 API 与独立会话。
- `scripts/build_global_journal.py`：读取包内公开门店目录，把资料写入页面数据块。
- `scripts/build_web_app.py`：生成线上页面、图片等静态资源与版本清单。
- `scripts/package_skill.py`：本地包包含页面、门店快照和图片。
- `web/global-journal.js`：门店搜索使用页面携带的目录；个人记录保存在浏览器中。

本说明根据 2026-10-10 的代码核对。新加的在线入口与说明不包含在已经构建的 v0.15.3 安装包里。
