# 产品顾问与反馈推进

目标是让用户轻松留下中国足迹：接入订单后自动整理门店资料，选择或上传照片，保存后能在地图与手账之间顺畅浏览。用户是否喜欢，以实际体验和反馈验证。

## 工作分工

- 主开发对话负责代码、数据接口、整合验收、版本交付及产品顾问审阅。
- “麦麦中国地图｜宣发与用户反馈”对话负责定位、渠道文案、体验招募方案和反馈记录，维护 `GROWTH.md` 与 `FEEDBACK.md`。
- 独立的门店资料、同步和测试子任务按文件范围协作，整合后由主开发验收。

## 文件和素材

`assets/data/store-directory.json` 维护公开示例门店，例如人民广场附近门店。个人订单对应的门店目录、地址、照片链接和手账留在 `private/`。公开页面、预览图、文案和发行包使用公开示例，不从私人订单取素材。

门店默认照片注明来源；用户上传后优先显示。备份保留用户照片和默认照片信息。来源明确的城市与省份自动整理，用户无需重复填写已查到的信息。

## 下一轮体验验证

1. 首次使用：能否从启动、接入订单到看到门店卡片顺利走通。
2. 照片：默认照片是否匹配门店，上传、替换和恢复是否直观。
3. 地图：新增记录后是否容易找到点位、省份和对应手账。
4. 保存：用户是否理解本地保存、导出和换设备恢复。

反馈记录需保留原话、发生步骤、环境和可复现证据。先解决阻止完成记录的问题，再优化高频困惑，最后评估新功能。没有收到真实体验反馈时，只保留待验证问题，不虚构好评或需求人数。

新文案或反馈出现后，主开发对照实际版本审阅，再把改进转成有完成标准的任务；未变化的状态不重复汇报。
