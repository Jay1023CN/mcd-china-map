# 麦麦中国地图：接下来做什么

让一顿麦留下记忆，也让人找到下次打开地图的理由。优先把“发现门店 → 收藏计划 → 到店手账 → 分享给朋友”这条体验做顺。

## 本轮：下一站计划（v0.12）

收藏按城市、关键词和日期筛选；标记优先想去、选择探店日期；“帮我挑一家”从当前筛选结果选择，连续点击换一家。复制当前清单给朋友，计划分享卡带上日期。日期与优先标记随备份恢复，到店后仍使用现有入口写成手账。

## 下一步优先：城市回忆册

把同一座城的门店照片、餐品和随手记串成一本可以翻的城市小册子。一座城逛过几家麦、一年里有哪些回忆，打开就能看；挑选喜欢的几页生成分享长图。现有“按城市搜索”继续用于查找，小册子负责回看照片和故事。

## 再做：每月麦麦小报

用当月真实手账自动整理本月走过的城市、最常吃的餐品和一张自己选的照片，生成月度小报。可以自己改标题和挑照片，发到群里交换本月探店发现。没有记录的月份不虚构内容。

## 配合出行：门店导航与朋友邀约

门店详情提供地图应用入口，带上店名和地址；从下一站计划生成带日期、照片和想去理由的邀约卡。城市路线需要可靠的门店坐标，再考虑距离排序与路径，不把城市中心点当成门店定位。

## 判断方向有没有用

先看实际使用中的几个问题：收藏之后能不能顺利找到；选日期和复制清单是否顺手；朋友收到分享后能不能看懂是什么店；到了店能不能少填几步留下手账。宣发对话记录真实反馈，再决定优先修哪一处，功能清单不能代替使用体验。
