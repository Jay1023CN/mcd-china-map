# 麦麦中国地图：接下来做什么

让一顿麦留下记忆，也让人找到下次打开地图的理由。优先把“发现门店 → 收藏计划 → 到店手账 → 分享给朋友”这条体验做顺。

## 已上线：下一站计划（v0.12）

收藏按城市、关键词和日期筛选；标记优先想去、选择探店日期；“帮我挑一家”从当前筛选结果选择，连续点击换一家。复制当前清单给朋友，计划分享卡带上日期。日期与优先标记随备份恢复，到店后仍使用现有入口写成手账。

## 本轮功能批次：城市回忆册、月度小报与地图入口（v0.13）

手账页自动按城市装订，展示照片、日期、餐品和随记。点击一页打开详情，再返回回忆册继续翻；跟随顶部年份、省份筛选，同名城市按省份区分。当前回忆册负责翻阅，城市整册分享长图留到后续打磨。

点击页面下方月份，自动整理该月页数、城市、门店和前三餐品；同一页重复填写的餐品只计一次。小报默认选最多三张不同照片，也可以指定一页照片作为封面。支持修改标题、隐藏城市名、配色、PNG 下载、复制文案与系统分享；可以返回换照片。月份从已有手账生成，空月份不增加内容。

特色门店详情、手账详情和想去清单提供高德地图搜索入口与店名 / 地址复制。带入店名、城市和已知地址，由地图应用继续选择地点与导航。链接按[高德官方 URI 搜索文档](https://developer.amap.com/api/uri-api/guide/search/search)生成。

## 接下来逐项打磨

- 回忆册：选页、调整封面、整城分享长图与翻页手感。
- 月度小报：多种版式、照片位置选择，带上更有记忆点的一句随记。
- 出行计划：更多地图应用、可靠门店坐标和城市路线；当前搜索入口只传文字，不使用城市中心假定位。
- 串联体验：从收藏到手账再到小报，依据实际反馈减少重复操作。

## 判断方向有没有用

先看实际使用中的几个问题：收藏之后能不能顺利找到；选日期和复制清单是否顺手；朋友收到分享后能不能看懂是什么店；到了店能不能少填几步留下手账。宣发对话记录真实反馈，再决定优先修哪一处，功能清单不能代替使用体验。
