# 麦麦中国地图｜可直接发布的文案与素材

当前目标：宣传必须与公开产品对得上，让麦门朋友点开手机网页就能留下第一条记录。项目与比赛信息仍是宣传重点。用户已表示“发在小红书了”，接下来准备抖音；帖子链接与实际数据尚未提供。

2026-10-10 手机网页已公开：[直接打开麦麦中国地图](https://jay1023cn.github.io/mcd-china-map/)。可记手账、拍照／选相册照片、看地图、按城市与特色词找店、收藏、生成分享卡和导出备份；个人记录留在当前浏览器。主开发已确认 v0.11.0 正式发布、目录为 28 家／19 城／15 省，Pages 与 Windows CI 成功，本对话未重复验收功能。[Windows 完整版](https://github.com/Jay1023CN/mcd-china-map/releases/tag/v0.11.0)作为本机官方门店查询与订单同步的备选入口。

网页使用静态模式，不发本机 API 请求，不需要安装 Python／运行 CMD，也不显示 Token 连接入口。官方 MCP 联网订单同步与更多门店查询目前只在本机完整版可用；手机端要等用户服务器接入后再上线。门店发现图层与个人足迹分开，公开店按城市参考点展示，不承诺全国完整目录或精确点位。

本机自 v0.9 起支持完成订单自动生成可编辑手账，匹配城市、省份与默认照片，可自行编辑、删除或换照片，无需逐条确认；当前公开版为 v0.11.0。主开发已验收删除后刷新和再次载入不恢复，本对话未读取私人订单或重复测试。历史版本更新帖保留原版操作，当前说明以公开手机网页和本机版分别支持的能力为准。
