## 修复与限制

显式 UTF-8 读取修复 Windows GBK 构建失败；固定字段顺序修复 Python 随机哈希导致构建结果变化；同步按运行隔离、失败保留旧数据、候选原子替换；启动支持 `-NoBrowser` 供测试。存储仍为本浏览器，无云同步。测试通过不代表替用户确认真实到访。
