## 报名正文

```text
【参赛申请】
项目名称：麦麦中国地图
项目地址：https://github.com/Jay1023CN/mcd-china-map
项目简介：麦麦中国地图用一家家去过的麦当劳，串起我们走过的中国城市。家门口的早餐、异地求学时的一顿饭、旅途中的一次歇脚，都能在地图上留下记录。项目通过麦当劳中国 MCP 整理历史订单，把门店、餐品、照片和随手记放在一起，慢慢形成自己的探店地图。麦当劳是熟悉的味道，地图上留下的则是每个人与祖国不同城市的联系。希望大家在记录一餐的同时，也多看看脚下这片土地，认识各地的生活，把对祖国的了解和喜爱留在真实的足迹里。
```
