```text
【参赛申请】
项目名称：麦麦中国地图
项目地址：https://github.com/Jay1023CN/mcd-china-map
项目简介：“麦麦中国地图”是一个用麦当劳门店串联个人城市足迹的记录项目。它通过麦当劳中国 MCP 整理历史订单，把去过的门店、餐品、照片和随手记汇集到地图上，逐步形成自己的探店地图。家门口的早餐、异地求学时的一顿饭、旅途中的一次歇脚，都能成为与城市相连的坐标。麦当劳是熟悉的味道，地图上留下的则是每个人与祖国不同城市的联系。记录一餐，也看看脚下的土地，认识各地生活，把对祖国的了解和喜爱留在真实足迹里。
```
