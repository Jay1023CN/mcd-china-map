# Windows 本地使用

解压完整包，双击 `麦麦中国地图/启动.cmd`，使用 <http://127.0.0.1:8765/>。普通手账无需 Python，保持窗口打开即可；关闭窗口停止服务。

已安装 Python 3.10+ 时，普通启动会自动启用连接入口。点击“连接麦当劳”在页面中输入自己的 Token，随后可以查询官方附近门店，或者点击“同步我的订单”直接载入待确认记录。不需要另开启动窗口或手动导入文件。Token 只在本次运行中使用。

此前用 `同步中国订单.cmd` 同步过的记录，点击“载入本机订单”即可恢复候选。隐藏输入 Token 的 `启动门店查询.cmd` 和命令行同步方式继续可用。

如果端口被其他应用占用，不会打开其页面。先关闭占用服务再启动；开发验证可以使用 `py scripts/local_api.py --no-browser --port 18765`，该临时端口使用独立浏览器存储。

定期导出 JSON 备份。没有云同步，换浏览器、清理网站数据或更换地址时需要备份恢复。演示地址为 <http://127.0.0.1:8765/docs/china-demo.html>，演示记录均为虚构。
