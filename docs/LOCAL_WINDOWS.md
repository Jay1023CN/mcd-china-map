# Windows 本地启动

1. 解压完整安装包，将里面的「麦麦世界护照」文件夹放在 `D:\coding\麦当劳\`。
2. 双击 `D:\coding\麦当劳\麦麦世界护照\启动.cmd`。
3. 浏览器会打开 `http://127.0.0.1:8765/index.html`。如果没有自动打开，复制这个地址到浏览器。

启动不需要安装 Node.js 或 Python，使用 Windows 自带的 PowerShell。请保持启动窗口打开；关闭窗口或按 `Ctrl+C` 会停止本地服务。服务只监听本机的 `127.0.0.1`，局域网里的其他设备无法访问。

如果提示端口 `8765` 已被占用，先关闭之前打开的启动窗口，再双击启动。启动失败时不会自动打开可能属于其他程序的页面。

## 记录与备份

请一直使用同一个浏览器、同一个浏览器个人资料，以及上面的固定地址。手账保存于这个浏览器的本地存储，不会自动上传 GitHub 或同步到其他设备。无痕窗口、清理站点数据、更换端口或浏览器都可能让已有记录不可见。

定期在网页中导出手账备份；重新导入可以恢复记录和照片。移动项目文件夹不会改变固定网址，但浏览器存储仍属于当前电脑与浏览器个人资料。

`docs/global-demo.html` 是明确标注的虚构演示，可通过 `http://127.0.0.1:8765/docs/global-demo.html` 查看。个人手账入口始终是首页。

## 中国大陆订单线索

全球打卡可以手动添加国家、城市、餐品、笔记与照片。麦当劳中国官方 MCP 只能提供中国大陆订单线索，不会自动提供全球消费记录，也不会把订单自动认定为本人到店。

可选的中国订单同步使用 `同步中国订单.cmd`；该步骤需要另行安装 Python，并配置你自己的 `MCD_MCP_TOKEN`。Token 不要写入源代码、备份或公开仓库。
