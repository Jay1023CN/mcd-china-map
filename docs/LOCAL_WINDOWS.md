# Windows 本地使用

解压完整包，双击 `麦麦中国地图/启动.cmd`，使用 <http://127.0.0.1:8765/>。普通手账无需 Python，保持窗口打开即可；关闭窗口停止服务。

已安装 Python 3.10+ 时，普通启动会自动启用连接入口。点击“连接麦当劳”在页面中输入自己的 Token，随后可以查询官方附近门店，或者点击“同步我的订单”自动整理完成订单为手账。不需要另开启动窗口或手动导入文件。Token 只在本次运行中使用。

此前用 `同步中国订单.cmd` 同步过的记录，点击“载入本机订单”即可自动整理为手账。隐藏输入 Token 的 `启动门店查询.cmd` 和命令行同步方式继续可用。

如果默认端口被其他应用占用，双击 `备用启动.cmd` 使用固定地址 <http://127.0.0.1:18765/>，不用关闭其他软件。两个入口都根据本机 Python 安装情况选择完整接口服务或普通手账模式。以后继续使用同一个入口；已有手账切换地址时，用 JSON 备份导入恢复。

定期导出 JSON 备份。没有云同步，换浏览器、清理网站数据或更换地址时需要备份恢复。演示地址为 <http://127.0.0.1:8765/docs/china-demo.html>，演示记录均为虚构。
