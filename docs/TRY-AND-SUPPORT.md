# 先试一站，再收藏作品

[打开麦麦中国地图](https://jay1023cn.github.io/mcd-china-map/) · [GitHub 项目仓库](https://github.com/Jay1023CN/mcd-china-map)

## 不用安装，先收藏一家店

1. 打开网页版，在「中国地图」选城市，或点地图上的城市标签。
2. 打开门店照片与介绍，点「想去这家」。
3. 去「想去清单」看刚收藏的门店，可安排日期、写理由或生成下一站计划卡。

收藏不会点亮到访足迹。目录目前收录 19 城、28 家特色门店，不是全国完整门店名单；地图使用城市参考点，具体位置请看门店地址。

## 记下自己的一餐

点「新增打卡」，或者在去过的门店详情点「我去过，记一餐」。填写省份、城市、门店、餐品和一句随手记；照片可以之后再补。保存后，地图和手账会更新。可从记录生成探店分享卡，再保存图片；系统分享与复制图片是否可用，取决于设备和浏览器。

同一城市的记录可整理成城市回忆册；按月整理成麦麦小报，选择照片和版式。分享前检查选中的内容，截图与公开示例不代表你本人到访。

## 喜欢的话，点颗 Star

1. 打开 [Jay1023CN/mcd-china-map](https://github.com/Jay1023CN/mcd-china-map)。
2. 登录自己的 GitHub 账号，在仓库顶部找到 **☆ Star**。手机布局不同，可能需要滚动到仓库顶部。
3. 点一次，显示 **Starred** 就已收藏；已经 Starred 时无需再点，重复点击会取消。

Star 在 GitHub 仓库页面操作，打开地图、下载和收藏门店都不会自动增加 Star。欢迎体验后按自己的判断支持；[反馈问题或推荐门店](https://github.com/Jay1023CN/mcd-china-map/issues/new/choose)也很有帮助。

## 使用前知道这两件事

- 记录和照片保存在当前浏览器，没有云同步。换设备、换浏览器或清理网站数据前，先点「导出备份」，在新设备导入 JSON 恢复。
- 公开网页版能手动记手账、收藏和分享，不需要 MCP Token。官方附近门店查询和完成订单同步通过[本机完整版](https://github.com/Jay1023CN/mcd-china-map/releases/latest)使用，需 Python 3.10+ 和自己的官方 MCP Token；它们不是公开手机网页已开放的功能。
