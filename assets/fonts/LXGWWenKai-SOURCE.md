# 霞鹜文楷

标题和短随记使用 LXGW WenKai Regular，地址、来源及操作保留清晰的正文字体。

- 官方项目：https://github.com/lxgw/LxgwWenKai
- 版本：v1.522
- 原始字体：https://github.com/lxgw/LxgwWenKai/releases/download/v1.522/LXGWWenKai-Regular.ttf
- 许可：SIL Open Font License 1.1，完整文本随本目录 `LXGWWenKai-OFL.txt` 分发。

`lxgw-wenkai-regular.woff2` 使用 FontTools 对官方完整字库压缩，保留全部字符与字体名称，不依赖外部字体服务。分享导出会等待字体加载完成。
