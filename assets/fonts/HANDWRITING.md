# 中文手账标题字体

标题、城市印章与三类 Canvas 分享卡使用 Ma Shan Zheng。正文保留 Noto Sans SC。

- 原始字体：[Google Fonts 官方仓库 MaShanZheng-Regular.ttf](https://github.com/google/fonts/blob/main/ofl/mashanzheng/MaShanZheng-Regular.ttf)。
- 作者：Copyright 2018 The Ma Shan Zheng Project Authors。
- 许可：SIL Open Font License 1.1，全文见 `MaShanZheng-OFL.txt`。
- 本地 `ma-shan-zheng.woff2` 是上述 TTF 的 WOFF2 无损压缩版本，保留完整字形集与字体元数据。压缩工具为 FontTools；没有裁掉用户自定义标题中的中文。
- 页面从本地资源加载字体；导出卡片等待标题字体加载，失败时回退到可读中文字体。
