# 门店目录来源

## 麦当劳上海黄浦华旭国际大厦餐厅

- 门店标准名称：麦当劳[餐厅信息公示](https://www.mcdonalds.com.cn/index/Quality/publicinfo/deliveryinfo?locale=zh&page=535&staticLinkId=886)列有“麦当劳上海黄浦华旭国际大厦餐厅”。
- 地址及旗舰店关联：上观新闻报道[上海麦当劳城市中心旗舰餐厅落址南京东路商圈](https://www.jfdaily.com/sgh/detail?id=1699951)，指出餐厅位于西藏中路336号，并介绍其CUBE旗舰店空间。麦当劳官网[开业新闻](https://www.mcdonalds.com.cn/news/20260123-Shanghai-City-Center-Flagship-Restaurant)将该店称为“上海黄浦华旭国际大厦CUBE风格旗舰店餐厅”。
- 默认照片：[上观新闻相关报道](https://www.jfdaily.com/sgh/detail?id=1699951)中的门店外观配图：[图片文件](https://sghimages.shobserver.com/img/catch/2026/01/24/7461e0ca-f1ce-4ee9-8bd0-993cfd1bcc62.jpg)。图片位于该店开业报道中，文章明确对应西藏中路336号的上海麦当劳城市中心旗舰餐厅；页面未见单独摄影署名。

此公开示例对应人民广场附近的华旭国际大厦餐厅。目录只保留可由来源核实的门店与照片信息。
